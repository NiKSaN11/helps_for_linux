## Мандатный контроль целостности (МКЦ)

```bash
sudo astra-mic-control enable   # disable / status
```

Или через GUI:

1. Открыть «Панель управления» (Пуск → Настройки → Панель управления).
2. Перейти в раздел «Безопасность» → «Политика безопасности».
3. Выбрать пункт «Мандатный контроль целостности».

Проверить статус:

```bash
sudo set-fs-ilev
```

## Мандатное управление доступом (МУД/МРД)

```bash
sudo astra-mac-control enable   # disable / status
```

---

## Запрет трассировки ptrace

Включить запрет (активировать блокировку ptrace):

```bash
sudo astra-ptrace-lock enable   # disable / status
```
