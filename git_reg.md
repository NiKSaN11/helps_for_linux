## Первичная настройка

### Указать имя и email

Они будут видны в истории коммитов:

```bash
git config --global user.name "Ваше Имя"
git config --global user.email "your-email@example.com"
```

## SSH-ключи

### Создание SSH-ключа

```bash
ssh-keygen -t ed25519 -C "nv4603060@yandex.ru"
```

### Вывести публичный ключ в терминал

```bash
cat ~/.ssh/id_ed25519.pub
```

Скопируйте содержимое (начинается с `ssh-ed25519`) и добавьте в GitHub:

> Settings → SSH and GPG keys → New SSH key

### Если утеряны ключи

```bash
ssh-keygen -t ed25519 -C "nv4603060@yandex.ru"
```

## Клонирование и заливка

Далее мы или **скачиваем** содержимое на ПК, или **заливаем** содержимое ПК в репозиторий.

### Скачиваем содержимое на ПК

```bash
git clone ssh-ссылка_к_репозиторию
```

### Заливаем содержимое ПК в репозиторий

#### Перейти в папку

Перейти в папку, которую будем синхронить с git:

```bash
cd путь/к/папке
git init
```

#### Добавить файлы в индекс

```bash
git add .
# или
git add файл1 файл2 файл3
```

#### Если ошибка доступа

```bash
git config --global --add safe.directory /путь/к/папке
```

#### Коммит изменений

Коммитим изменения (или заливаем целиком):

```bash
git commit -m "сообщение об изменении"
```

#### Примонтировать репозиторий

```bash
git remote add origin git@github.com:username/repo-name.git
```

#### Проверка монтирования

```bash
git remote -v
```

#### Проверка ветки

```bash
git branch
```

#### Push коммита

```bash
git push -u origin ветка
```

## Проблемы и решения

### Если не пушится

Скорее всего, недоступен дефолтный порт 22 — меняем на 443:

```bash
nano ~/.ssh/config
```

Содержимое файла:

```
Host github.com
    Hostname ssh.github.com
    Port 443
    User git
    IdentityFile ~/.ssh/id_ed25519

Host ssh.github.com
    Hostname ssh.github.com
    Port 443
    User git
    IdentityFile ~/.ssh/id_ed25519
```

#### Настроить права

```bash
sudo chmod 700 ~/.ssh
sudo chmod 600 ~/.ssh/config
sudo chmod 600 ~/.ssh/id_ed25519
sudo chmod 644 ~/.ssh/id_ed25519.pub
sudo chmod 600 ~/.ssh/known_hosts
```

#### Добавить ключ

```bash
ssh-add ~/.ssh/id_ed25519
```

### Если работаешь с одной папкой с разных машин

```bash
git config --global --add safe.directory /home/astra/nikonov
```
