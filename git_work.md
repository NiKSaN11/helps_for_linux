## Работа с историей

### Увидеть историю изменений файла

```bash
git log --follow --oneline -- путь/к/файлу
```

### Увидеть конкретные изменения

```bash
git log -p -- путь/к/файлу
# или
git log -- путь/к/файлу
```

### Вытянуть конкретный коммит

```bash
git checkout HEAD~1 -- путь/к/файлу   # через последний коммит
git checkout <commit> -- путь/к/файлу # по конкретному коммиту
```

### Закоммитить и запушить

```bash
git commit -m " "
git push   # в гите этот коммит станет последним
```

### Сравнение двух версий

```bash
git diff <хэш_коммита1> <хэш_коммита2> -- путь/к/файлу
```

### Посмотреть старую версию

```bash
git show <хэш_коммита>:путь/к/файлу
# для сохранения в файл добавить:
git show <хэш_коммита>:путь/к/файлу > 123.txt
```

### Заменить текущую версию на старую

```bash
git checkout <хэш_коммита> -- путь/к/файлу
# или
git checkout <хэш_коммита> -- путь/к/папке
```

## Репозитории

### Клонирование репозитория

```bash
git clone origin master
# или с SSH:
git clone git@github.com:username/repository.git
```

### Создание нового репозитория

```bash
mkdir my-project
cd my-project
git init
```

### Добавление в индекс и коммит

```bash
git add .
# или
git add имя_файла
git commit -m "описание изменений"
```

### Загрузить свои изменения на GitHub

```bash
git push origin ветка
```

### Загрузить обновления с GitHub

```bash
git pull origin ветка
```

---

## Ветки

### Узнать текущую ветку

```bash
git branch
```

### Создать новую ветку

```bash
git branch новая-ветка
```

### Переключиться на ветку

```bash
git checkout новая-ветка
# или:
git switch новая-ветка
```

### Создать и переключиться

```bash
git checkout -b новая-ветка
```

### Удалить ветку

```bash
git branch -d имя-ветки
```

## Origin

### Проверить текущий origin

```bash
git remote -v
```

### Удалить привязку к origin

```bash
git remote remove origin
```

### Переименовать origin в upstream

```bash
git remote rename origin upstream
```

## Полезные команды

### Проверить статус

```bash
git status
```

### Перенести коммиты в другую ветку

```bash
git rebase новая_ветка
```

### Отменить коммит по id

```bash
git revert id_коммита
```

### Просмотреть историю коммитов

```bash
git log --oneline
```

### Отменить изменения в файле

```bash
git checkout -- имя_файла
```

### Проверка подключения к GitHub

```bash
ssh -T git@github.com
```
