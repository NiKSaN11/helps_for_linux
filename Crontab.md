## Примеры расписаний

### Синхронизация и сборка репозитория

```bash
0 6 * * * bash /scriptsrepo/reposync_stable.sh
0 6 * * * bash /scriptsrepo/build/make_repository.sh -s -u -f
```

## Редактирование

### Открыть crontab в nano

```bash
sudo EDITOR=nano crontab -e
sudo EDITOR=/usr/bin/nano crontab -e
```

---

## Формат записи

```
30    6    *    *    1
│     │    │    │    │
│     │    │    │    └─── день недели (1 = понедельник, 0 или 7 = воскресенье)
│     │    │    └──────── месяц (1-12, * = каждый месяц)
│     │    └───────────── день месяца (1-31, * = каждый день)
│     └────────────────── час (0-23)
└──────────────────────── минута (0-59)
```

## Логи и мониторинг

### Посмотреть, когда срабатывал и с какими командами

```bash
sudo grep CRON /var/log/cron
```

### Мониторинг доступа крона к папке

```bash
* * * * * ls -la /mirror/inftest-drv/stable >> /tmp/cron_mount_test.log 2>&1
```

Через минуту:

```bash
cat /tmp/cron_mount_test.log
```
