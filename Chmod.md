## Синтаксис

```bash
chmod [опции] права файл_или_каталог
```

Ключ `-R` меняет права всех вложений.

## Типы прав

В Linux есть три типа прав:

- `r` (4) — чтение (read)
- `w` (2) — запись (write)
- `x` (1) — выполнение (execute)

## Категории пользователей

Три категории пользователей:

- `u` (user) — владелец файла
- `g` (group) — члены группы владельца
- `o` (others) — все остальные пользователи

## Проверка прав

```bash
ls [ключи] /путь/
```

- ключ `-l` — длинный список с правами
- ключ `-a` — скрытые и системные файлы
- ключ `-R` — вывод полного древа

## Права в 8-ричном формате

```bash
stat -c "%a" файл_папка   # например 755
```

## Типы файлов

В записи `-r-xr-xr-x` первый символ означает:

- `-` — обычный файл (regular file). Самый распространённый тип: текстовые документы, изображения, исполняемые программы, архивы и т.д.
- `d` — каталог (directory)
- `l` — символьная ссылка (link)
- `c` — символьное устройство (character device)
- `b` — блочное устройство (block device)
- `p` — именованный канал (pipe)
- `s` — сокет (socket)
