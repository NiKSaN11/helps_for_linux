## Генерация ключа

### Генерация ключа

```bash
sudo gpg --gen-key
# или
sudo gpg --full-generate-key   # даёт на выбор больше параметров
```

---

## Удаление ключа

### Удаление ключа

```bash
gpg --delete-secret-key "идентификатор_или_имя_пользователя"
```

---

## Экспорт ключа

### Экспорт секретного ключа в файл

```bash
sudo gpg --export-secret-keys --armor 2FAEA6812A300BC5C34B95CBCC344EECF1B73897 > private.key
```

### Экспорт с кодированием

```bash
gpg --export-secret-keys --armor 2FAEA6812A300BC5C34B95CBCC344EECF1B73897 | gpg --symmetric --cipher-algo AES256 -o private-key.encrypted.gpg
```

### Раскодирование

```bash
gpg -d private-key.encrypted.gpg | gpg --import
```

---

## Импорт ключа

### Импорт секретного ключа из файла

```bash
gpg --import private.key
```

---

## Просмотр ключей

### Вывод ключей

Для пользователя и sudo вывод отличен:

```bash
gpg --list-keys
```

### Вывод секретных ключей

```bash
gpg --list-secret-keys
```
