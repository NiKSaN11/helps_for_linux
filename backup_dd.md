## Определите размеры разделов на источнике (sdb)

```bash
sudo fdisk -l /dev/sdb
```

Вы увидите что-то вроде:

```
/dev/sdb1  2048    ...   размер EFI (обычно 100-500 МБ)
/dev/sdb2  ...     ...   размер
/dev/sdb3  ...     ...   размер
/dev/sdb4  ...     ...   размер
```

Запишите или запомните размеры и порядок разделов.

---

## Скопируйте таблицу разделов с sdb на sda

Так как sda не размечен, проще всего скопировать разметку один-в-один:

```bash
sudo sfdisk -d /dev/sdb | sudo sfdisk /dev/sda
```

---

## Скопируйте каждый раздел отдельно с помощью dd

Теперь копируем содержимое разделов. Важно: разделы должны быть **НЕ примонтированы** (вы же с Live USB, это условие соблюдено).

```bash
sudo dd if=/dev/sdb1 of=/dev/sda1 bs=64K status=progress
sudo dd if=/dev/sdb2 of=/dev/sda2 bs=64K status=progress
sudo dd if=/dev/sdb3 of=/dev/sda3 bs=64K status=progress
sudo dd if=/dev/sdb4 of=/dev/sda4 bs=64K status=progress
```

Если в будущем понадобится восстановить только sdb2 — вы это сделаете за минуты.

---

## Проверьте результат

После копирования всех разделов:

```bash
sudo fdisk -l /dev/sda
```

Вы должны увидеть те же разделы, что и на sdb.

## Восстановление загрузчика (если система не загрузится)

Иногда после такого копирования UEFI может не увидеть загрузчик. Чтобы это исправить (из Live USB):

```bash
# Примонтируйте корневой раздел и EFI
sudo mount /dev/sda2 /mnt
sudo mount /dev/sda1 /mnt/boot/efi

# Смонтируйте служебные директории
sudo mount --bind /dev /mnt/dev
sudo mount --bind /proc /mnt/proc
sudo mount --bind /sys /mnt/sys

# Войдите в окружение восстанавливаемой системы
sudo chroot /mnt

# Переустановите GRUB для UEFI
grub-install --target=x86_64-efi --efi-directory=/boot/efi --bootloader-id=ubuntu

# Обновите конфигурацию
update-grub

# Выход из chroot
exit

# Отмонтирование
sudo umount /mnt/dev /mnt/proc /mnt/sys /mnt/boot/efi /mnt
```

## Альтернатива: копирование всего диска одной командой

Если вам всё же проще скопировать весь диск целиком (несмотря на возможную разницу в размерах), это делается так:

```bash
sudo dd if=/dev/sdb of=/dev/sda bs=64K status=progress
```

Это скопирует и таблицу разделов, и все данные в один проход. Но:

- sda должен быть не меньше sdb (даже на 1 байт — и будет ошибка или обрезка).
- Вы не сможете прервать и продолжить.
- При восстановлении на больший диск лишнее пространство останется неиспользуемым.
