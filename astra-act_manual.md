## Инструкция по настройке доступа к приватным репозиториям

## Для Astra Linux

### 1. Разместить Сертификат и ключ

Полученные Сертификат и ключ необходимо разместить в:

```
/etc/lk/certs
```

### 2. Изменить права на файлы сертификата и ключа

Чтобы они были доступны только для чтения и записи пользователю `_apt`:

```bash
sudo chmod 600 /etc/lk/certs/client.crt
sudo chmod 600 /etc/lk/certs/client.key
sudo chown _apt /etc/lk/certs/client.crt
sudo chown _apt /etc/lk/certs/client.key
```

### 3. Отредактировать `/etc/apt/sources.list`

Добавить в конец файла строки для подключаемых репозиториев:

```bash
deb https://dl.astralinux.ru/content/neo-repo-1.7 1.7_x86-64 main contrib # Neo-repo 1.7. Доступ к репозиторию NeoRepo, где хранятся предварительно проверенные и протестированные Группой Астра свободные программные компоненты, доступные для дальнейшего скачивания и использования совместно с операционной системой специального назначения "Astra Linux Special Edition". Группа Астра не предоставляет право использования программных компонентов, а обеспечивает доступ к репозиторию NeoRepo с целью скачивания и использования совместно с операционной системой специального назначения "Astra Linux Special Edition".
deb https://dl.astralinux.ru/content/neo-repo-1.8 1.8_x86-64 main contrib # Neo-repo 1.8. Доступ к репозиторию NeoRepo, где хранятся предварительно проверенные и протестированные Группой Астра свободные программные компоненты, доступные для дальнейшего скачивания и использования совместно с операционной системой специального назначения "Astra Linux Special Edition". Группа Астра не предоставляет право использования программных компонентов, а обеспечивает доступ к репозиторию NeoRepo с целью скачивания и использования совместно с операционной системой специального назначения "Astra Linux Special Edition".
```

### 4. Создать или отредактировать `/etc/apt/apt.conf.d/02_ssl.conf`

Добавить в него следующее содержимое:

```
Acquire::https::dl.astralinux.ru {
  SslCert "/etc/lk/certs/client.crt";
  SslKey  "/etc/lk/certs/client.key";
  Verify-Peer "true";
};
```

### 5. Выполнить команду

```bash
sudo apt update
```
