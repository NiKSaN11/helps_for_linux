## Визуализация и мониторинг контрольных групп

```bash
systemd-cgls
systemd-cgtop
```

## Список запущенных служб

```bash
systemctl --type=service --state=running
```

## Какие службы будут запущены при загрузке

```bash
systemctl --type=service --all
```

## Зависимости службы

```bash
systemctl list-dependencies <service_name>
```

## Кто зависит от сервиса

Показывает, какие юниты зависят от данного сервиса (кто его требует):

```bash
systemctl list-dependencies --reverse <service_name>
```

## Логи службы с указанного времени

```bash
journalctl -u <service_name> --since today
```

## Логи службы в реальном времени

Режим follow — выводит текущие логи и показывает новые записи по мере появления:

```bash
journalctl -u <service_name> -f
```

## Все логи с момента последней загрузки

```bash
journalctl -b
```

Что привело к падению системы в прошлый раз:

```bash
sudo journalctl -b -1
```
