# РЕШЕНИЕ № ОВИ1-26

## О присвоении IP адресов изделиям и/или составным частям

### 1. Единая подсеть

- **Диапазон адресов:** `192.168.100.x`
- **Маска подсети:** `255.255.255.0`

### 2. Логика распределения адресов

- **.1** — Шлюз / Основной коммутатор (если имеется)
- **.2-10** — Статические адреса управляющих ЭВМ изделия и LXI-приборов
- **.11-99** — Статические адреса модулей контроллеров системы
- **.100-254** — Резерв

---

В целях унификации сетевых настроек и оптимизации процесса отладки оборудования принимается **Решение:**

Для одиночных изделий (на базе одного крейта стандартов AXIe-0 или AXIe-1), а также для многокрейтовых систем на базе стандарта VXI устанавливается единая подсеть.
